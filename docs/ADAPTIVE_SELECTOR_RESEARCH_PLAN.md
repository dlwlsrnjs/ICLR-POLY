# PolyJigsaw: 학습 기반 적응형 선택기 연구 계획

작성: 2026-09-03

상태: 사용자가 선택한 주된 연구 후보. 아래는 검증할 설계이며, 학습 완료나 성능 개선을 주장하는 문서가 아니다.

기존 상태 및 평가 오류: [연구 재개용 검토](RESEARCH_REVIEW_2026-09-03.md).

## 연구 질문

재구성 능력과 안전 응답 성향이 다른 대상에서, 구조화된 설정과 평가 이력을 사용하는 학습 정책이 제한된 평가 예산으로 일반화하는가?

핵심 주장은 세 부분으로 분리해 검증한다.

1. 구조: 언어 수와 순서 유형만으로 표현할 때 놓치는 구성 차이가 실제로 중요하다.
2. 적응: 처음 한 번 선택하는 정책보다 관측 결과를 반영하는 정책이 유용하다.
3. 전이: 학습한 대상과 문항을 암기하는 수준을 넘어 새로운 대상과 문항에서도 이점이 유지된다.

RL 사용 자체나 탐색 공간의 크기 자체를 독립적인 신규성으로 주장하지 않는다. 검증 결과에 따라 세 주장 중 지지되는 범위만 논문에 포함한다.

## 기존 연구와 연결

| 기존 자산 | 새 연구에서의 역할 | 주의점 |
|---|---|---|
| Interleaving 구성 및 평가 파이프라인 | 구조화된 설정을 평가하는 공통 기반 | 새 구성에서도 의미 보존과 파싱 유효성을 확인해야 함 |
| Reconstruction-gated 평가 | 외부 안전성 평가에서 의미 복원과 응답 판정을 구분 | 기존 자동 판정기의 오류를 정답으로 간주하지 않음 |
| Capability/alignment probe | 대상 특성을 나타내는 후보 정보 | 각 정보의 취득 시점과 평가 비용을 명시 |
| Capability–difficulty 모형 | 어떤 정보가 필요한지 설명하는 경험적 가설 및 비교군 | 모든 대상에 성립하는 법칙으로 가정하지 않음 |
| 기존 BO | 평가 오류를 수정한 비교군 | 현재 질의 효율 숫자는 재사용하지 않음 |
| 저장된 격자 결과 | 기존 조건에서의 재현 및 분석 자료 | 미평가 구성의 결과를 제공하는 완전한 환경이 아님 |

## 의사결정 문제의 범위

초기 주 실험의 적응 단위는 **대상별 설정 선택**으로 둔다. 문항별 개인화는 별도의 후속 확장으로 취급한다. 두 단위를 섞으면 개선 원인과 일반화 단위를 구분하기 어렵다.

- 대상은 한 적응 과정 동안 고정한다.
- 정책이 보는 정보는 해당 시점까지 실제 취득한 대상 특성, 평가 이력, 남은 예산이다.
- 설정은 언어 구성, 조각화, 배열을 식별할 수 있는 구조화된 객체로 표현한다. 세부 허용 범위는 데이터 점검 후 실험 manifest에 동결한다.
- 하나의 완전한 구성을 내부적으로 여러 단계에 걸쳐 출력하는 것과, 외부 평가 피드백을 받아 다음 선택을 바꾸는 것은 구분한다.
- 정책의 종료 시점 판단과 최종 설정의 독립 평가는 분리한다. 전체 후보의 실제 최댓값은 사후 분석 전용이다.
- 정책 학습, 적응 중 평가, 최종 성능 보고에 쓰이는 정보를 각각 구분한다. 최종 평가용 점수가 온라인 정책에 미리 노출되면 안 된다.

확장된 환경의 인터페이스는 우선 무해한 재구성 과제에서 확인한다. 설정 유효성, 이력 기록, 예산 처리 및 종료가 제대로 동작하는지 검증한 후 외부 안전성 평가와 연결한다. 이것만으로 안전성 평가 성능의 전이가 입증되지는 않는다.

정책 아키텍처와 RL 알고리즘은 아직 고정하지 않는다. 관측 형태와 실제 피드백 비용을 확인하기 전에 큰 모델이나 특정 알고리즘을 연구의 전제로 삼지 않는다.

## 필요한 비교 실험

| 비교군 | 검증할 질문 |
|---|---|
| 학습 자료에서 선택한 공통 고정 설정 | 대상별 적응이 필요한가? |
| 같은 예산의 무작위 탐색 | 학습이 기본 탐색보다 나은가? |
| 수정된 BO 및 밴딧 | 기존 적응형 탐색을 넘어서는가? |
| 대상 특성만 사용하는 1회 선택기 | 반복적인 피드백의 추가 가치가 있는가? |
| 순차적 학습 정책 | 관측 이력이 예산 배분과 최종 선택에 도움이 되는가? |
| 이력 정보를 제거한 정책 | 순차성의 기여가 실제로 존재하는가? |
| 구조 정보를 단순화한 정책 | 세부 구성 표현의 기여가 실제로 존재하는가? |

가능한 비교군에는 동일한 후보 공간, 사전 정보, 판정 방식, 평가 예산을 제공한다. 별도 사전학습 자료를 사용하는 방법은 그 비용과 자료를 명시한다. 전체 공간을 평가하지 못한 경우 측정된 최선값을 전역 oracle이라고 부르지 않는다.

## 일반화 및 비용 평가

- 문항 분할: 동일 원문의 번역과 구성 변형은 같은 분할에 둔다.
- 대상 분할: 정책 학습과 설정 선택에 사용하지 않은 대상에서 평가한다. 가능하면 같은 계열의 크기 변화와 다른 모델 계열로의 전이를 구분한다.
- 선택 규율: 정책 아키텍처, 특징, 종료 조건은 validation에서 결정하고 test를 보고 고치지 않는다.
- 평가 단위: 설정 평가 횟수와 문항별 대상 호출 수를 따로 기록한다. 판정 호출 수, 토큰, 실행 시간도 별도 보고한다.
- 비용 범위: 사전 자료 수집과 정책 학습 비용을 포함한 전체 비용, 학습 이후 신규 대상 적응 비용을 함께 보고한다.
- 성능: 같은 예산에서의 독립 평가 결과와 불확실성을 비교한다. 최선의 한 seed나 평가 모델 평균만으로 결론을 내리지 않는다.
- 계측: 과거 관측은 보존하며, 재평가하면 추가 비용으로 센다. 예산 내 미도달은 실제 도달 횟수와 분리한다.

현재 데이터는 일부 집계만 확인됐으며 원시 자료 전면 접근, 확장 공간의 관측 범위, 후속 probe 완료 여부는 별도 점검이 필요하다. 기존 5/6모델 격자를 반복 샘플링해도 새로운 독립 대상이 늘어나는 것은 아니다.

## 진행 순서와 판단 기준

1. **자료 및 계측 정리:** 기존 결과의 데이터 분할, 판정기, 설정 및 호출 비용을 연결한다. 기존 BO의 계수/관측 오류를 먼저 해결한다.
2. **환경 정의 검증:** 구조화된 설정, 유효성 조건, 관측 기록, 비용 및 종료 규칙을 무해한 재구성 과제로 검증한다.
3. **학습 가능한 정보 확인:** 대상 특성과 구성 정보가 단순 고정 선택보다 유용한지 1회 선택기와 비교한다.
4. **순차적 RL 검증:** 같은 예산에서 피드백 이력의 효과를 비교한다. 이력이 도움이 되지 않으면 순차적 RL의 필요성을 주장하지 않는다.
5. **독립 일반화 평가:** 새로운 대상/문항에서 개선과 총비용을 평가하고, 확인된 범위에 맞춰 본문을 수정한다.

단계별 수치 기준은 파일럿의 분산과 비용을 확인한 후 validation 단계에서 고정한다. 아직 측정되지 않은 목표 개선 폭이나 예상 학습 비용을 결과처럼 기재하지 않는다.

## 논문에서의 위치

가제: Learning Adaptive Configuration Policies for Reconstruction-Based Safety Evaluation.

도입의 문제는 대상마다 다른 재구성 및 안전 응답 특성을 고정 설정이 충분히 반영하지 못한다는 것이다. 방법의 기여는 구조를 표현하고 관측에 따라 선택을 갱신하는 정책이다. 결과에서는 구조 표현, 이력 활용, 대상 간 일반화의 기여를 각각 검증한다.

기존 안전성 실험은 현상과 평가의 근거로 유지하고, 능력–난이도 분석은 가설로 연결한다. 학습 정책의 결과가 나오기 전에는 초록이나 기여 목록에 RL 성능 우위를 확정적으로 쓰지 않는다.

## 직접 관련된 선행연구

- [MetaBO, ICLR 2020](https://iclr.github.io/build/virtual/poster_ryeYpJSKwr.html): 관련 문제들에서 RL로 BO의 획득 함수를 학습한다. 학습한 탐색 규칙의 전이 측면에서 비교할 연구다.
- [Auto-RT, ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/717557c7edac0142fef45a66d54c1b33-Abstract-Conference.html): RL 기반 자동 레드팀 전략 탐색. 자동화 또는 RL 도입만으로 신규성을 주장할 수 없음을 보여준다.
- [LMABO, ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/f1b7a29fe9759d4c9d23f78738e40b42-Abstract-Conference.html): 현재 최적화 상태를 바탕으로 LLM이 획득 함수를 선택한다. 이력 및 상태 활용과 RL 학습의 효과를 구분해 비교할 연구다.

위 연결은 공식 초록에 근거한 초기 위치 설정이다. 정확한 재현 범위와 방법 간 차이는 각 논문의 본문 및 실험 프로토콜을 대조해 확정한다.


## 기존 데이터 자산을 이용한 학습 설계 — 2026-09-03 추가

사용자 제안인 ‘기존 데이터셋을 여러 모델과 여러 설정에서 평가해 적합한 설정을 학습’하는 방식은 가능한 출발점이다. 원문 데이터셋은 평가할 문제를 제공하고, 실제 모델별 실행 로그는 설정 선택에 필요한 관측을 제공한다.

### 추가로 확인한 자료

원문을 포함하지 않는 점검 결과는 `docs/RL_DATA_ASSET_AUDIT_2026-09-03.json`에 저장했다.

- 기존 paper_main의 Qwen3-8B, Phi-3.5-mini, GPT-4o-mini, Mistral-7B, Qwen2.5-32B 패널을 확인했다.
- 대상 출력 총 16,820행에 대응하는 재구성 로그가 연결됐다. 안전성 평가 arm에서는 안전 판정도 연결됐다. 각 run/arm 내부 item_id+condition 중복과 대응 response_sha256 불일치는 없었다.
- 재구성/안전 판정의 parse-valid 플래그는 점검 범위에서 모두 유효했다. JSON boolean뿐 아니라 정수 1도 사용한다. 이것은 판정 내용의 정확성 검증과 다르다.
- 모델 간 공통 ID는 benign 40개, 안전성 평가 250개이고 공통 조건명은 각각 10개다. 16,820행은 서로 다른 원문 16,820개를 의미하지 않는다.
- 공통 ID와 조건명만으로 입력 구성, 디코딩 및 판정 버전까지 동일하다고 단정할 수 없다. run/protocol 정보가 추가로 필요하다.
- 점검한 로그에는 seed 필드가 없어 정확한 구성은 원 입력/실행 기록과 연결해야 한다.
- 후속 panel_v2는 이 시점에 9개 모델의 benign/harmful 집계가 존재한다. 일부 원시 디렉터리는 OS 권한 때문에 동일 수준으로 점검하지 못했다. 기존 패널과 대상이 겹치므로 두 패널의 모델 수를 단순히 합치면 안 된다.

### 학습 데이터의 단위

설정별 평균만 사용하지 않고 아래 정보를 연결한다. 원문/응답 본문은 기존 접근 제한 저장소에 두고, 일반 보고서는 메타데이터와 집계만 사용한다.

| 요소 | 필요한 정보 | 목적 |
|---|---|---|
| 문제 | 원문 그룹 ID, 데이터 출처, split, 선택 전 특징 | 번역/변형의 분할 누출 방지 |
| 대상 | 모델/버전, 생성 모드, 사전 probe 출처 | 대상 일반화 및 조건 일치 확인 |
| 구성 | 구성 ID, 실제 언어 구성·조각화·배열 복원 근거 | 조건명이 같아도 다른 실행을 구분 |
| 결과 | 재구성/평가 판정, 유효성, judge 버전 | 신뢰도와 재판정 관리 |
| 비용 | 실제 호출, 토큰/시간, 측정 여부 | 관측된 비용과 추정 비용 구분 |
| 계보 | run ID, 원 출력 해시, 재판정 연결 | 다른 실행의 결과를 잘못 합치는 것 방지 |

최종 응답에서만 알 수 있는 성공 여부를 초기 선택기의 입력에 넣지 않는다. 모델 이름을 외우는 선택기와 사전 probe 특징으로 새 대상에 일반화하는 선택기를 구분한다.

### 1단계: 기존 결과를 이용한 성능 예측 및 1회 선택 학습

문제/대상/구성의 선택 전 정보를 입력으로 받고, 기존 실행 결과를 감독 신호로 활용한다. 주어진 후보들의 성능 예측 또는 순위 학습이 공통 고정 설정보다 유용한지 먼저 평가한다. 이것은 지도학습으로 시작할 수 있다. 기존 데이터가 있다는 이유만으로 offline RL이라고 부르지 않는다.

초기 학습·검증 환경은 무해한 재구성 과제로 둔다. 작은 표형 예측기 또는 구성 인코더를 기준선으로 삼고, 큰 언어 모델 미세조정을 기본 가정으로 두지 않는다. 한 번의 실행으로 고른 단일 최선 설정을 확정 정답으로 만들면 잡음과 동률에 취약하므로 전체 관측 결과를 보존한다.

기존 안전성 판정은 독립 결과 분석에 보존한다. 무해한 과제에서 학습한 선택기가 안전성 평가에도 유용한지는 별도 실험으로 검증한다. 두 목적의 동일성을 가정하지 않는다.

### 2단계: 관측된 후보에서 순차적 선택 검증

초기 순차 환경은 무해한 재구성 평가에서 아래와 같이 정의한다.

| 요소 | 정의 |
|---|---|
| Episode | 한 대상, 고정 calibration 문항 묶음, 명시된 평가 예산 |
| Observation | 허용된 대상 특징, 지금까지의 선택과 관측, 남은 예산 |
| Action | 유효 후보의 다음 평가 선택 또는 종료 후 최종 추천 |
| Transition | 새 관측과 실제 지출을 이력에 추가; 기존 관측은 보존 |
| Feedback | 검증된 재구성 품질 및 비용; 파싱 오류는 별도 표시 |
| Final evaluation | calibration과 다른 문항에서 최종 추천을 평가 |

훈련용 후보 결과가 충분히 기록된 부분에서는 선택된 관측만 공개하는 replay 환경을 만들 수 있다. 전체 성능표는 정책에 먼저 보여주지 않는다. 실행 순서가 결과에 영향을 주지 않는 독립 평가라는 가정도 확인해야 한다.

replay는 기록된 후보에 한정된 경험적 환경이다. 기록에 없는 조합의 결과를 알려주지 못한다. 같은 관측을 반복해도 새 독립 측정이 되지 않는다. 예측 모형으로 채운 결과는 simulator 실험으로 표시하고 실제 평가 결과와 혼합하지 않는다.

관측표에서 인위적인 순서를 만들어 학습하는 경우, 이를 과거에 실제 실행한 적응형 탐색 궤적이라고 부르지 않는다. 같은 성능표에서 만든 수천 episode는 수천 개 독립 대상과 다르다.

### 3단계: 여러 모델에서의 자료 확장과 일반화 평가

모델군과 원문 그룹을 추가 실행 전에 train/validation/test로 고정한다. 같은 원문의 번역·배열·조각 변형은 한 그룹에 둔다. 같은 모델 계열의 크기 변화와 다른 계열로의 전이를 분리한다.

전체 원문 × 모든 모델 × 모든 구성을 처음부터 실행할 필요는 없다. 공통 비교 구간을 확보하고 확장된 구성에서 어떤 관측이 있는지 coverage를 명시한다. 누락을 실패로 바꾸거나 선택된 성공 사례만 모으지 않는다. 기존 10개 조건을 재사용하는 실험과 확장된 구성에 일반화하는 실험을 구분한다.

새 안전성 평가를 수행할 때는 기존 공개 벤치마크 범위와 독립 판정 절차를 유지한다. 원시 유해 출력의 취급에는 기존 저장소의 접근 제한 규칙을 적용한다.

### 이번 설계의 결정 사항

1. 배포 단위는 우선 대상별 설정 선택으로 유지하되 학습 데이터는 문항 단위 결과를 보존한다. 문항별 선택기를 추가하면 별도 실험으로 보고한다.
2. 기존 관측은 성능 예측/1회 선택 학습과 제한된 replay에 먼저 활용한다. 이력이 주는 이점을 검증한 뒤 순차 정책의 역할을 판단한다.
3. 정책 아키텍처와 RL 알고리즘은 데이터 범위와 피드백 비용을 확인한 뒤 선택한다. 특정 대형 모델을 먼저 고정하지 않는다.
4. 주요 비교는 고정 설정, 무작위 탐색, 수정된 BO/밴딧, 1회 선택기, 이력 기반 정책이다. 동일 후보/정보/예산을 사용한다.
5. 이미 본 대상의 새 문항, 새 대상의 새 문항, 새 구성으로의 전이를 구분한다. 최종 독립 평가에는 정책 학습 및 선택에 사용하지 않은 자료를 쓴다.
6. 학습과 자료 수집의 전체 비용, 학습 후 신규 대상 적응 비용을 함께 보고한다.

### 관련 근거

과거 튜닝 자료에서 정책과 성능 예측을 학습하는 발상은 [OptFormer, NeurIPS 2022](https://proceedings.neurips.cc/paper_files/paper/2022/hash/cf6501108fced72ee5c47e2151c4e153-Abstract-Conference.html)와 연결된다. 해당 연구의 대규모 자료와 현재 소수 모델 패널의 차이는 명시해야 한다.

기존 데이터로 정책을 학습할 때의 관측 범위 및 분포 차이는 [Levine et al., Offline Reinforcement Learning](https://arxiv.org/abs/2005.01643)의 검토 주제다. 관측 재사용이 가능하다는 사실과 미관측 행동의 성능을 신뢰할 수 있다는 주장은 구분해야 한다.
