# C3 확정: 언어 + 퍼즐 복잡도는 대상별로 적응 조절되며, 어떤 단일 고정 설정보다 낫다

작성 2026-09-05. 라이브 수집(GPU1, target vLLM + Qwen2.5-7B/Qwen3Guard-8B judges 공존).
데이터: `results/harmful_weaklang_20260904/` (8대상 × {n2,n3,n4} × {고정언어, 무해-약한언어}).

## 배경 — 왜 새 실험이 필요했나

기존 유해 factorial(`frag_factorial_20260903`)의 모든 arm은 **고정 언어 순서**(`select_languages`)를
쓴다. 그래서 복잡도(n) 축만 바뀌고, C1에서 무해로 확인한 **"언어 적응"** 이득을 유해 ASR로
검증할 수 없었다. 복잡도만 바꾸는 적응은 고정과 거의 동률(−0.008, `adaptive_benign_20260904`)이었다.
→ 언어 축을 실제 유해 공동 ASR로 직접 테스트하는 라이브 실험을 새로 수집했다.

## 설계

각 대상에 대해, 무해 스윕(`benign_recon_sweep_20260904`)에서 읽은 **해독 최강 단일 언어들**로
`EN + top-(n-1) 언어` 설정을 만들어, 같은 n/F/배열의 **고정 언어 순서** 설정과 40문항 유해에서
공동 ASR(재구성 게이트 AND 응답 unsafe)로 맞비교. 언어 선택에는 **유해 감독을 쓰지 않는다**
(무해 해독 프로파일에서만 고름).

## 결과 (공정 비교: 전대상 공통 단일 고정 vs 대상별 적응)

**단일 고정(n=2, 모든 대상 동일) 평균 공동 ASR = 0.491**

| 정책 | 라이브 유해쿼리 | 평균 | vs 고정 | 이김 |
|---|---|---|---|---|
| P0 무해만 (무해 최강 단일 언어, n2) | 0 | 0.566 | **+0.075** | 6/8 |
| **P1 온라인** (무해 warm-start + n을 라이브로 선택) | ~3 | 0.584 | **+0.094** | **7/8** |
| P2 온라인풀 (6설정 라이브 탐색) | ~6 | 0.619 | **+0.128** | 7/8 |

per-target(P1): falcon +0.25(Japanese), phi35 +0.225(German), granite +0.125, zephyr +0.125(Arabic),
mistral +0.10(Norwegian), qwen3_4b +0.05, qwen25_7b +0.025, **yi −0.15(반례)**.

## 해석 — 논문 논리

1. **적응이 필요하다(C1, 유해로 확정):** 대상별 최적 언어가 다르다 — Japanese/German/Arabic/
   Norwegian/Russian 5종. 하나로 고정 불가. falcon은 고정 언어로 0.10인데 Japanese로 0.35(3.5배).
2. **무해가 언어를 골라준다(전이):** 라이브 유해 쿼리 0개(P0)로도 무해 해독 최강 언어만 넣어
   고정 대비 +0.075(6/8). 무해→유해 전이가 **언어 선택**에서 작동.
3. **복잡도는 소수 라이브 쿼리로 마무리(하이브리드 정당화):** 무해 해독은 항상 가장 단순한 n2를
   선호(단조)하므로 복잡도 U-최적점은 못 짚는다. 무해로 언어를 warm-start하고 n만 ~3쿼리로 고르면
   +0.094(7/8). 이것이 **오프라인 프라이어 + 온라인 적응** 설계의 실증적 근거다.

## 유효-대상 패널 (다국어 재구성 불가 모델 제외, 2026-09-05 사용자 지시)

zephyr7b(무해해독 0.054, 최강 언어도 0.17, n8/n10=0.00)과 falcon3_7b(0.170, n8/n10=0.00 즉시 붕괴)은
다국어 재구성이 **아예 안 되는** 모델 = 유효 공격 대상이 아니므로 baseline에서 제외한다. yi(0.306)는
경계로 유지(민감도로 함께 보고). 제외 시 **고정 baseline이 n2→n3로 강해진다**(약한 모델이 고정을 n2로
누르던 효과가 사라짐): 8대상 고정 n2=0.491 → 6대상 고정 n3=0.542.

| 정책 | 6대상(고정 n3=0.542) | 5대상(제외+yi, 고정 n3=0.545) |
|---|---|---|
| P0 무해만 (0 쿼리) | 0.571 (+0.029, 3/6) | 0.590 (+0.045, 3/5) |
| P1 온라인 (무해+~3쿼리) | 0.596 (+0.054, 4/6) | 0.620 (+0.075, 4/5) |
| P2 온라인풀 (6설정 라이브탐색) | 0.642 (**+0.100**, 5/6) | 0.645 (+0.100, 4/5) |

## 정직한 한계 — 전이가 깨지는 조건 (yi)

yi는 무해 최강 언어(Russian)가 오히려 공동 ASR을 낮췄다(−0.15). 무해 프록시는 **재구성 R**만
재는데, yi는 Russian을 잘 해독하지만 Russian에서 **안전 정렬(U)이 강해** 거절한다. 대부분 대상은
"해독 약함 ≈ 정렬 약함"이 성립하지만 yi는 예외. 그래서 언어를 무해로 warm-start해도 **최종 확정은
유해 공동 ASR 라이브 쿼리로** 해야 한다(P1가 P0보다 나은 이유). corr(무해해독, 최적언어이득)=−0.03
로 "약한 대상일수록 이득"이라는 단순 메커니즘은 성립하지 않는다 — 이득은 언어-정렬 상호작용에서 온다.
