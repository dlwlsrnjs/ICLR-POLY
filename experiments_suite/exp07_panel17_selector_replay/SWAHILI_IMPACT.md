# 스와힐리 재수집이 기존 결론에 준 영향 (2026-09-15)

MultiJail 번역 baseline을 벵골어에서 스와힐리로 바꾼 뒤 모든 결론을 다시 계산했다.
**영향 범위가 깔끔하게 갈린다.**

## 1. 주 결과(24 arm 격자)는 전혀 바뀌지 않는다

권고 공간은 이해 격자만 쓰고 공개공격 arm을 포함하지 않는다. 그래서 번역 arm 교체와 무관하다.
소수점까지 동일하다.

| 공간·지표 | 벵골어 | 스와힐리 |
|---|---|---|
| 24 arm, verified, GP@8 | 0.507 | 0.507 |
| 무작위 대비 | +0.049 (7/7, p=0.0156) | +0.049 (7/7, p=0.0156) |
| 24 arm, 기본ASR, GP@8 | 0.666 | 0.666 |
| 무작위 대비 | +0.019 (7/7, p=0.0156) | +0.019 (7/7, p=0.0156) |

Lingua는 양쪽 수집 모두 노르웨이어라 애초에 영향이 없다. 즉
[FINAL_ARM_SPACE.md](FINAL_ARM_SPACE.md)의 권고와 수치는 그대로 유효하다.

## 2. 공개공격을 포함한 공간에서는 크게 바뀐다

| MultiJail, 24 arm + 공개공격 4 | 벵골어 | 스와힐리 |
|---|---|---|
| 번역 arm 자체 | 0.516 | **0.687** |
| 공개공격 4개 전수(예산4) | 0.778 | **0.804** |
| 계열 LOO 고정 최선 | 0.490 | **0.643** |
| 우리 GP@8, verified | 0.647 | 0.668 |
| GP@8 vs 공개4전수, verified | -0.131 (0/7) | -0.136 (1/7) |
| GP@8 vs 공개4전수, 기본ASR | -0.052 (3/7, p=0.63) | **-0.090 (0/7, p=0.0156)** |

기본 ASR에서 전에는 비유의하게 뒤지던 것이 이제 **유의하게 진다.** 논문과 언어를 맞추자 공개 공격
진영이 강해졌기 때문이다.

## 3. MultiJail의 승자 구조가 바뀐다

| MultiJail 164 arm | 벵골어 verified | 스와힐리 verified |
|---|---|---|
| 고정 최선 arm | m_deepinception (0.571) | **m_translated (0.665)** |
| 번역이 승자인 셀 | 6/17 | **10/17** |
| 평문 arm이 승자인 셀 | 15/17 | 16/17 |
| 계열 순열 p | 0.0257 | **0.2492** |
| 오라클 | 0.803 | 0.825 |

**"승자가 모델 계열을 따라간다"는 서술이 스와힐리에서는 성립하지 않는다.** 저자원 번역 하나가
17개 중 10개에서 최선이 되면서 계열 구조가 흐려졌다. 기본 ASR에서도 순열 p가 0.169에서 0.797로
올라간다.

## 4. 논문 서술에 반영할 것

1. 주 결과는 24 arm 격자이고 이번 재수집과 무관하다. 그대로 쓴다.
2. 외부 공격 비교에서는 저자원 번역을 **스와힐리로** 보고한다. 논문 수집과 같은 언어이고 값도
   복원된다(9모델 0.563 대 0.547).
3. MultiJail에서 "승자가 계열을 따라간다"는 문장은 쓸 수 없다. 저자원 번역이 지배적이라고 쓰는 편이
   데이터에 맞다.
4. 공개 공격 전수 대비 열세가 커졌다는 점을 한계에 명시한다. 기본 ASR에서 -0.090으로 유의하게 뒤진다.
5. 두 언어를 모두 보관하므로 저자원 언어 선택 민감도를 부록에 실을 수 있다. 같은 "가장 저자원 언어"
   규칙으로 고른 두 언어가 17모델 평균 0.473과 0.665로 갈린다는 것 자체가 보고할 만한 결과다.
